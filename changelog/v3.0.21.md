## Summary

* 設定JSONファイルで定数の宣言とその参照，及び四則演算による値の設定ができるように機能追加

## 設定JSONファイルでの定数宣言・参照・四則演算

以下のように設定JSONファイルに`CONSTANTS`フィールドを設定すると，その値は定数として設定ファイルの中で参照できるようになりました．
定数の参照は`!`から始まる文字列で記述します．
同様に，`!COMPUTE(`から文字列が始まる場合，その引数に対して四則演算をした結果を浮動小数点数で設定します．

以下に例では，`!COMPUTE(TX_GAIN - OFFSET)`は`25`になります．

```json
{
    ...
    "CONSTANTS": {
        "SAMPLE_RATE": 200e6,
        "FREQUENCY": 2.4e9,
        "TX_GAIN": 30,
        "OFFSET": 5,
    },
    "devices": {
        "USRP0": {
            "type": "MultiUSRP",
            ...
            "tx-channels": [
                {
                    "for-channels": [0],
                    "rate": "!SAMPLE_RATE",
                    "freq": "!FREQUENCY",
                    "gain": "!COMPUTE(TX_GAIN - OFFSET)",
                    "ant": "TX/RX"
                }
            ],
        }
    },
    ...
}
```
