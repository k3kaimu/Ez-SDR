## "devices"と"controllers"の初期化・起動順序を指定できるように変更

以前のバージョンでは，"devices"と"controllers"の初期化・起動順序は不確定であり，またユーザーから指定することができませんでした．
本バージョンからは，順序をユーザーが指定できるようになりました．

以前のバージョンでは，設定のJSON形式の`devices`と`controllers`は以下のようにオブジェクト形式のみで指定できました．

```json
{
    ...
    "devices": {
        "USRP0": {
            ...
        },
        "USRP1": {
            ...
        }
    }
    ...
}
```

このとき，以前のバージョンでは，`USRP0`が先に初期化されたり，`USRP1`が先に初期化されるなど，その順序が不確定であり，またユーザーは指定できませんでした．
本バージョンからは，このような場合は必ずキーの順番で初期化されるようになり，つまり必ず`USRP0`から初期化され，その次に`USRP1`が初期化されます．

また，`devices`と`controllers`には以下のように配列を設定することも可能になりました．

```json
{
    ...
    "devices": [
        {
            "name": "USRP0",
            ...
        },
        {
            "name": "USRP1",
            ...
        }
    ]
    ...
}
```

このように配列で設定した場合は配列に書かれた順番で必ず初期化されます．
また，オブジェクト形式で指定していたキーは，"name"で指定する必要があります．


### 変更の背景

特にUSRPでPPSを共有している場合に，PPS信号を出力する端末から順番に起動しないと起動に成功しない問題がありました．
そのような問題を解決するために，起動順序をユーザーが指定できるように変更を加えました．
